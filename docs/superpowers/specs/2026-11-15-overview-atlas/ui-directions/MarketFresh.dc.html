Methodology

How the numbers are made, in plain words. Placeholder copy for this mockup.

Forecasts are projections

Each forecast names the model that made it, or the simpler fallback when the model could not run. Missing demand stays missing; it is never shown as zero.

How transfers are suggested

Two methods solve the same problem under the same limits, so their plans can be compared side by side. An independent check verifies each plan.

What this does not do

It does not reserve stock or dispatch trucks. Ranges are not calibrated probabilities.
