**Data (frozen, saved; nothing computed client-side beyond same-product sums).** Saved comparisons from `GET planning-catalog` (`comparisons[]`, default newest) → `GET comparisons/{id}` (`SavedComparison`) + `GET scenarios/{scenario_id}`; plan ids and `result_hash` from `GET allocation-jobs/{comparison_id}/results` (comparison id equals its job id — `apps/api/app/workers/optimization.py:177`).
- *Actions* = `methods[m].candidate.assignments` of the selected **VERIFIED** method (`outcome == "VERIFIED"` and `verification.passed`). Each: `source_id → destination_id` (names from `scenario.payload.package.sites`), `units` + `unit`, `departure`, `arrival`, `expires_on` (or "non-expiring"), `original_lot_id`, `cost_minor` as "simulated cost points". Destination's first projected deficit from `verification.projection.days`.
- *Deficit tag* (display only, Q-54-1): "Deficit <date>" / "No deficit in window" — no Critical/High/Medium/Low unless the user publishes thresholds.
- *Plan-level impact* (whole plan vs no-transfer baseline, per product, same unit only): unmet units `baseline_metrics.goals` → `verification.metrics.goals`; beneficiaries with unmet > 0 before → after; served/target; projected expired units (`waste_by_product`) before → after; cost points. Header text: "Whole-plan projection on frozen scenario <id>; not attributable to one transfer (V5 OPEN-02)."
- *Remaining unmet need:* per beneficiary × product with `unmet > 0` after the plan.
- *Site Recommendations:* filter by site; lists that site as **receiving** and/or **sending** rows, its reserve floors (`package.reserves`), affected lots, and residual unmet.
- *Network Optimization:* method pair header (both methods' outcome/native status/verification), same frozen scenario/mode/hashes, verified constraint list (FEFO, donor reserve, capacity, conservation — only as "passed independent replay"), uncovered demand, `Open in Scenario Lab` link (`/scenarios?comparison=<id>`). Runs nothing.
- *Impact & Fairness:* per goal `target`, `fulfilled`, `unmet`, `service_ratio` (`N/A` when null), `deficit`, `weighted_deficit`, `vulnerability`, `ap`, `rp`; group `ap_count`/`rp_count`/`size` per product. Rationals shown as decimals with ≤4 places and exact fraction on hover/details.

**States.** Loading; visitor (Q-54-3); no saved comparison ("Run a comparison in Scenario Lab" link); comparison `PARTIAL` (one method failed → its tab shows the error code, the other stays usable; never substitute); `FAILED` (no actions, explain); method VERIFIED with **zero assignments** ("No feasible transfer with current resources" + residual unmet); stale/historical flags → banner "Sources changed since this scenario was frozen; review is still a simulation"; `GET comparisons` 409 `COMPARISON_NOT_PUBLISHED` → "still computing" notice; review 409 `PLAN_REVISION_MISMATCH` → stale message, no retry loop; review 401 → session expired; network failure → alert + Retry. Native `FEASIBLE` labeled "feasible, not proven optimal"; `UNKNOWN`/`MODEL_INVALID` never show actions.

**Accessibility and motion.** Order: header select → tabs → sort/filter → rows (each row a button-like row; Enter selects) → Impact Preview → review button → dialog.
