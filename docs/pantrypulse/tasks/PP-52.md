## Decisions (user, 2026-10-25)

1. **Draggable map nodes.**
   - Pantries and the hub can be dragged on the map, and their supply links follow live.
   - Positions are saved per browser (guarded localStorage, schema-versioned, per site id). A visible "Reset layout" control restores `atlas-layout.ts` defaults.
   - Clamp drops inside the placeable map area: never under the docked card band, the legend card or the zoom controls, and never off-map. Dragging must not trigger selection; a click or tap without movement still selects.
   - Keyboard alternative: with a node focused, a "Move" mode (e.g. press `M`, then arrow keys move it in 8px steps, Enter or Esc to finish) with screen-reader announcements.
   - Works on touch (pointer events) and doesn't break map pan/zoom: dragging a node moves the node, dragging empty map pans.
2. **Draggable floating panels.**
   - The legend card, the desktop inspector and the docked selection card can be moved inside the map by a visible drag handle (a grip icon with an accessible name), clamped within the map. Positions are saved per browser, and "Reset layout" also resets them.
   - Default positions must keep every existing invariant: the card never covers the selected marker or the inspector, and so on. Those existing tests run on the default layout, so clear storage in tests.
   - Keyboard: the handle supports arrow-key moves.
   - At 390px, panels stay where they are now (the sheet and docked card); no dragging on mobile.
3. **Spring motion from the design lab** (`type: "spring"`, around stiffness 250 / damping 22):
   - marker select and hover scale;
   - drag pick-up (lift and shadow) and spring settle on drop;
   - panel enter/exit (AnimatePresence for the card and inspector content);
   - staggered marker entrance on load;
   - chip and button press feedback;
   - status glyph changes on product/day switches;
   - the chart's line animation stays.
4. **Flowing links, always on, on ALL supply links.** This is an explicit user override of ART-DIRECTION's ban on perpetual motion and blueprint §3.
   - Animate a dash flow from hub to pantry continuously, as in `.lab-edge-flow`, using tokens, not hard-coded colours. The selected site's link flows brighter and faster.
   - Keep the legend text exactly: "Supply link: the hub can send to this pantry; not a planned route or shipment". The flow must not suggest quantities.
   - Honour `prefers-reduced-motion`: a static line. The user deprioritised reduced-motion polish, but OS reduced motion must still stop all perpetual motion.
5. **Dark/light theme toggle** in the shared top bar. It's an icon button with an accessible name ("Switch to dark theme"/"Switch to light theme") and uses `applyTheme`/`currentTheme` from `lib/theme.ts`. It works on every page that uses the shell (/overview, /optimization). Check that every overview surface uses tokens and reads well in dark: map texture, links, glyphs, legend, inspector, card, notices, chart axes and lines (Recharts strokes via CSS vars), and the provenance pills.
